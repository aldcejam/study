# 🌉 UE - Design de APIs - GraphQL e API Gateway

## 🎯 Objetivo
Estudar como expor serviços e dados de forma eficiente para diferentes tipos de clientes, controlando acesso, roteamento e composição de dados.

## 📝 Tópicos
- API Gateways (Kong, KrakenD, AWS API Gateway)
- Backend for Frontend (BFF)
- GraphQL vs REST na exposição de dados
- Autenticação e Rate Limiting na borda
