# 📨 UE - Message Brokers vs Event Streaming - RabbitMQ e Kafka

## 🎯 Objetivo
Compreender as diferenças fundamentais entre filas tradicionais e streaming de eventos, e como desenhar arquiteturas assíncronas resilientes.

## 📝 Tópicos
- Message Brokers (RabbitMQ, ActiveMQ) vs Event Streaming (Kafka, Kinesis)
- AMQP vs Padrão de Log Anexado (Append-only log)
- Garantias de entrega (At-most-once, At-least-once, Exactly-once)
- Arquitetura Orientada a Eventos (EDA)
