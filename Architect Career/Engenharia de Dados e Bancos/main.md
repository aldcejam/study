# 🗂️ Engenharia de Dados e Bancos

## 🎯 Escopo da Área
Dados são o ativo mais valioso de qualquer sistema moderno. Entender como eles são persistidos fisicamente (B+Trees vs LSM-Trees) e como as transações garantem integridade (ACID, ARIES) é vital para evitar **perda de dados** e **corrupção de estado**.

O arquiteto deve saber escolher a Storage Engine correta para cada carga de trabalho (OLTP vs OLAP) e como otimizar consultas complexas.
